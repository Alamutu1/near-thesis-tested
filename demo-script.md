# Demo video script outline — Thesis Agent (under 3 minutes)

Phase 0 note (1 Nov 2026): a demonstration video following this script
was prepared for the builder's private review only. It has NOT been
published to YouTube, X, or any other platform, and must not be published
without the builder's separate approval. This outline follows one arc only:
problem in one sentence, what the user does, what the agent does, what
the result is.

## The arc (say this, in this order)

- **Problem, one sentence:** "A thesis often hides three or four claims in
  one sentence, and nobody says what would prove any of them."
- **What the user does:** Types a thesis and presses "Break it down".
- **What the agent does:** Splits it into checkable parts, each with a
  measure, the evidence it needs, and a pass rule, and lists one checker
  job per part inside the user's spending cap.
- **What the result is:** A test plan the user can mark part by part and
  download, with no verdict decided for them.

## Shots

### Shot 1 (0:00–0:20) — problem

On screen: the Thesis Agent page.
Voiceover: the problem sentence above, nothing else.

### Shot 2 (0:20–1:10) — user action, agent action

1. Press "Try example 1".
2. Press "Break it down".
3. Show the test plan: effect claimed, cause claimed, falsification
   check, each starting as "Not yet tested". The demo does not decide
   for you.

### Shot 3 (1:10–1:50) — user decides, result appears

1. Type an evidence note on one part.
2. Change its status to "Supported by evidence".
3. Show the progress bar moving.
4. Press "Download test plan (.md)" and show the downloaded plan.

### Shot 4 (1:50–2:40) — the NEAR idea, stated honestly

On screen: the spending cap and the "Show the NEAR plug-in point
(dry run)" output.
Voiceover: "In the full Agent Economy design, a checker agent would be
paid for one sub-claim at a time, only after it records named evidence,
and only inside a cap you set. That payment step is shown here as a
dry run only. No transaction is sent in this demo."

### Shot 5 (2:40–2:55) — close

On screen: the repository link and the track name, Agent Economy.
Voiceover: "Thesis Agent, built for NEAR HACKATHON. Try it, break a
thesis down, and tell us what evidence you would check first."
