Thesis Agent

Take a thesis or claim, break it into parts you can actually check, and build a test plan for each part. No verdict is given for you. You add the evidence, then you mark each part yourself.

Built by Cryptoearn Gives, solo. The core thesis tool runs in your browser, signs nothing, and moves no money. Live quote, link check, and testnet proof panel send only the requests you trigger, described below.

Your plan is saved in this browser only (localStorage, no server) so a refresh keeps it. Clear saved plan removes it.

Why NEAR, and not just any chain

    
The reason it fits NEAR is specific: a checker agent may live on one chain and be paid from another, and NEAR Intents are built for exactly that kind of cross-chain intent, stated once and settled where the work happens, without the user bridging wallets by hand. The spending cap above is the other half: an agent that can spend, but only inside limits the user sets, and only released when evidence is recorded. That is the Agent Economy idea in one sentence: hire an agent for a verifiable job, pay it only for that job, and never hand it the keys to everything.

    
Two real, limited NEAR proofs now exist alongside this page, and are documented in README.md and HACKATHON.md: a dry-only live Intents quote (the button in Step 3, no payment, no deposit address) and a testnet escrow contract (thesis-agent-escrow2.testnet, testnet only, with real testnet release and refund transactions). This page itself still has no wallet and moves no money.

    
If those proofs did not exist, this would still be a working thesis-testing tool. The NEAR part is the reason it would scale as an agent market, not the reason the demo opens.
